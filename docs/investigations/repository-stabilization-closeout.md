## 3. 明确保留的复杂实现与边界

- 货币战争单方案 API 仍服务 CLI 和现行算法测试，不是废弃包装；批次／候选类型、完整配置排除、共享预算、Worker 取消和独立验证器均保留。
- 三套工具的纯 TypeScript 业务引擎及各自 UI／Domain／Data 边界保持独立；只共享完全相同的图片 UI 状态，不统一业务模型或引入状态管理框架。
- 行动序列的 AV/SPD、排序、生命周期、当前队列时点、存档保护、Version 1/2→3 与 11 组历史迁移基准保留；未改引擎、文件模型或测试夹具。
- Warp 概率、保底、RNG 消耗、状态转移、星缘草稿、历史及当前批次身份保留；目录双语名称仍是展示权威来源。
- 维护脚本、独立 Manifest／Source Lock、原始来源通知、资源清单、空正式模板及遗器施工入口继续保留。
- 不合并三个更新器的事务、锁和回滚机制。它们的发布范围和恢复语义不同，不能为了减少代码行数引入统一发布抽象。
- 保留原 CI 范围与精确依赖版本。完整维护矩阵写入开发指南，不在本轮改变自动工作流或部署行为。
- 源码字符串边界测试仍保护页面不运行求解器、引擎隔离、卡片身份与 reduced-motion；本轮只整理有明确重复的图片断言，没有批量改写测试框架或新增 CSS 快照。
