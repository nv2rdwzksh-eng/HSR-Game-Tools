## 页面结构与职责

页面顶部保留标题、当前卡池摘要和控制／历史入口。两个 PrimeVue Drawer 默认关闭，左控制宽 25rem、右历史宽 49rem，均不超过视口且互斥打开。中央结果常驻；单抽／十连、选择状态、星缘入口及错误提示位于带 safe-area 的 sticky 操作栏，抽取不依赖控制抽屉展开。

`WarpSimulatorPage` 负责展示与已有业务动作连接；`useWarpSimulator` 原字节保留。新增 `useWarpOverlay` 仅保存面板、Dialog 转场回调和返回焦点 ID，无会话／引擎／RNG 依赖。从抽屉进入星缘、重置或详情时等待 after-hide，再开 Dialog；Dialog 退出后恢复来源抽屉与原触发项，普通抽屉关闭返回顶部入口。操作栏星缘入口确认后变为编辑而保持同一 ID，避免恢复到已移除按钮。

`WarpItemDetails` 共用于结果和历史，展示名称、类别、星级、命途、角色属性、来源、可靠事件 UP、五星当次保底数及记录编号。Dialog 的打开关闭不产生业务提交。星缘与重置继续使用原有草稿、确认和取消逻辑。

## 横向卡片与历史

`WarpResultCard` 是无常驻物品文字的 PrimeVue Button：左图、右 Icon，支持 Hover Tooltip、ARIA 和点击／Enter／Space 详情。只额外展示事件 `isUp === true` 的 UP，不实现 NEW。`WarpItemVisual` 区分艺术图与共享头像；角色完整展示透明立绘，光锥在独立留白容器内保持封面完整，不使用 cover 裁切。`WarpVisualIcon` 共用安全加载／失败占位。

单抽最大宽 620px。十连继续使用八列 Grid、双列跨度与第 1／8 项起点偏移形成 3–4–3，DOM 顺序与实际抽取顺序相同。为防止中等视口下图标被挤压，<1040px 提前降为两列，≤400px 一列；这是相对原计划 ≤640px 开始降级的细化。卡片最小高 136px，未使用绝对坐标。

稀有度颜色集中于 preset：三星蓝 `#69b6f5`、四星亮紫 `#c593ff`、五星亮金 `#f2cc76`，2px 边框加柔和静态外光和轻内光，强度递增。作用域限于结果卡，无倾斜、星空、持续闪烁或复杂演出。180ms／7px／逐张 50ms 的原入场方式及 reduced-motion 保留；结果 key 仍为批次 ID＋条目 ID，不由语言、面板或图片状态驱动。

`WarpHistory` 改为语义 table，依次为名称、类别、原生星级图、命途图标＋名称、属性图标＋彩色名称。名称列占弹性宽度并截断／Tooltip，其余列稳定对齐；光锥属性留空。表格最小宽 660px，窄屏由表格区域横向滚动。原有最新优先、每页 25 条、最近 1000 条、分页及条目身份不变；辅助事件详情从名称按钮访问。

Sharp 0.35.3：角色最长边 768、光锥 640，quality 82；命途／属性图标 64、星级图 160，quality 90；统一 alphaQuality 100、inside、withoutEnlargement。源内容哈希与转换参数共同作为去重键，目标为 `public/game-assets/warp/<hash>.webp`。共享资源通过规范化 Catalog 与原 Manifest 验证后复用，不在维护时按 ID 猜路径。

只读取中英文 characters、light_cones、paths、elements 八份索引。物品 canonical ID 保留类别前缀；命途使用 `Warrior`／`Knight`／`Priest` 等内部身份。`createPresentation` 增加可选 definitions 参数，返回命途／属性双语名称和图标、艺术图、头像与星级 URL；名称、类别和稀有度继续来自 Warp Snapshot。相同 Adapter 服务历史、结果和详情，光锥不生成属性字段。

属性保留来源六位颜色。原色在历史 Surface `#22252b` 上低于 4.5:1 时，逐步采用最小幅度白色混合；原始色不改写，量子等低对比颜色只调整展示色。缺少映射／资源时省略 URL 并记录诊断，加载失败显示中性占位；未虚构资源路径。

Manifest 包含源 Commit、八份索引及图片的来源路径／SHA-256／bytes、共享投影来源哈希、Warp Snapshot 哈希、转换参数、Sharp 版本、输出尺寸／哈希／bytes 和缺失项。staging 校验通过后仅发布自有图片目录和展示目录；安装失败恢复两者，回滚失败保留恢复材料。并发锁和异常测试均使用系统临时目录。

排轴 validator 仅新增对 `game-assets/warp/` 的明确归属排除，其余哈希、尺寸与严格 inventory 保持不变；该目录由 Warp validator 检查。排轴旧 updater 整目录发布的限制未改动，维护指南明确要求以后运行前备份 Warp／星徽目录并恢复后分别验证。本轮未运行排轴 updater。

## 未支持项与本地人工验收

当前可达的 86 件物品资源完整；未提取完整上游目录，未来新增物品须显式更新。没有 NEW、持久化、云同步、统计、新卡池或完整跃迁演出。没有使用 Computer Use、Playwright、Puppeteer 或浏览器截图；资源与代码检查不能代替真实交互验收。

1. 使用 Node 24，运行 `npm run dev`，打开 `/warp-simulator`。检查默认抽屉收起、卡池摘要、空结果和未完成选择说明；普通启动不需要三个来源仓库。
2. 在中文／英文及 1440／1024／390px 下检查页面、抽屉、长名称和底部操作栏。1440px 核对十连 3–4–3，1024px 两列，390px 单列；历史只在自己的容器横向滚动。
3. 用键盘打开左右 Drawer，检查互斥、Tab 范围、Escape／关闭／遮罩及返回顶部触发项焦点。控制中打开星缘和重置，确认抽屉先关闭、Dialog 正常工作、退出后回到原面板及按钮。
4. 从常驻操作栏完成七名选择并取消／确认／重新编辑，确认按钮保留且可恢复焦点；收起控制后仍可单抽／十连，取消不会改变已提交选择。
5. 检查角色面部与完整立绘、光锥封面、命途／属性图标、Star3／4／5、紫／金边框的清晰度与柔和发光。结果无常驻名称；Hover、触屏点击、Enter／Space 均可查看详情，Escape 返回卡片。
6. 对照十连实际顺序与历史最新优先顺序，检查历史五列、名称截断、光锥属性留空、量子文字可读性、UP／来源／五星保底详情及分页。
7. 抽取后反复开关面板、切换语言、翻页及查看详情，确认结果与保底不改变，结果入场动画不重播。启用 reduced-motion，模拟图片请求失败，检查无动画及中性占位。
8. 分别取消和确认当前组／全部重置，检查原有范围、历史身份和选择保留规则；离开并返回确认内存会话清空。回到 Action Planner 与货币战争确认既有主要操作可用。

完成本轮后停止，等待维护者人工验收，不自动进入下一阶段。
