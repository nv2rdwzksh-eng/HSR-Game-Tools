## 交付与职责

新增纯展示组件 WarpRevealMetadata，输入为当前 ItemPresentation、已生成事件的 rarity 和 descriptionId。内部只使用 computed 和现有 i18n，不保存演出状态、不发送操作或 ready 事件。小型 reveal-metadata 展示函数负责字段过滤、本地化摘要及可见性判断，供组件与 Node 测试共用；不按名称查找物品、不导入数据源或消耗 RNG。

只在 WarpRevealOverlay 原 Artwork 容器中增加面板和 aria-describedby。Presentation Adapter、资源契约、素材／Manifest／Source Lock、普通结果卡、WarpVisualIcon、WarpRevealImage、历史与演出状态机均保持本轮起点字节。

面板为三行可见结构：

| 行       | 内容与默认规格                                                                        |
| -------- | ------------------------------------------------------------------------------------- |
| 名称     | item.name，26px／600，使用已有三星蓝／四星紫／五星金 Token                            |
| 稀有度   | cardStars 的裁切星级图，目标高 22px，共同参考比保持单颗星尺度及自然比例               |
| Metadata | 命途 Icon＋名称；仅角色追加属性 Icon＋名称；图标 22px、文字 14px，组内 6px、组间 16px |

命途中性色，属性直接使用 elementTextColor；无属性颜色时中性回退。没有分组名称则省略该组，光锥始终不显示属性。两组均缺失时第三行显示现有本地化“未知”；有名称但图标缺失／失败时保留文字与中性图标占位，裁切星级缺失／失败也使用现有占位，不替换 Unicode 星星或回退长空白星级。所有文本使用 Vue 插值，无 HTML 注入。

## 定位、排版与响应式

本轮已明确选择**现有 Artwork 舞台左下角**：最大宽 1200px、居中的 .warp-reveal-artwork 容器。图片仍按原视口、DPR 和自然尺寸限制居中；面板不跟随实际图片外框，也不锚定 Viewport。光锥使用这一较宽舞台，避免把整个面板压在狭窄封面内。

- 背景 rgba(0,0,0,0.75)，Padding 16px、left／bottom 各 16px、行距 8px、圆角 6px。
- 宽度 min(360px, 100% - 32px)，不加边框、渐变、模糊、阴影或发光动画。
- 宽度 ≤640px 或高度 ≤480px 使用紧凑规格：Padding／偏移 12px，宽度 min(320px, 100% - 24px)，名称 20px、星级高 18px、图标 20px、Metadata 文字 13px，组间横向间距 12px。
- 名称完整换行、overflow-wrap anywhere；第三行可组间换行，组内图标与文字垂直居中，不截断 Metadata。
- 面板建立 inline-size 容器，复用既有裁切星级的统一高度约束；图标和星级均保持原始比例。样式只限定新增面板。
- pointer-events none，不引入链接、按钮、tabindex 或新焦点目标，面板区域点击继续由全屏按钮处理。

实际光学位置、人物主体遮挡、长名称的面板高度、宽屏／高 DPR 下的图像与面板距离，以及明亮素材下属性文字可读性仍需人工验收。属性颜色按已确认方案直接复用现有 Adapter，不增加新颜色算法或修改资源。

## 显示时序与无障碍

面板挂在图片所在的原 .warp-reveal-artwork 父容器内，随既有 400ms 淡入；没有新动画类、Transition、计时器或阶段。

| 情况                          | 面板行为                                              |
| ----------------------------- | ----------------------------------------------------- |
| identity，含 Artwork 已预加载 | 不挂载面板                                            |
| Artwork 未就绪                | 不挂载；保持原加载与 Escape 行为                      |
| artwork 就绪并开始淡入        | 图片与面板共同淡入                                    |
| waiting                       | 图片与面板持续停留，等待原确认操作                    |
| 最终 Artwork 的 leaving       | 根据 Overlay 已保留的显示阶段保留面板，与图片共同淡出 |
| identity 直接 Escape 离场     | 不出现面板                                            |
| Reduced Motion                | 原流程资源就绪后直接显示最终图与面板，仍须确认        |
| 下一个五星／新批次            | 沿用 batchId／entryId key，替换成对应物品的面板       |

面板图片加载不进入 Artwork 或 identity ready 门控，坏星级／图标不会延迟确认或推进队列。前置点击只跳当前 Artwork、淡入期间点击不推进、waiting 确认、Escape、重复输入、滚动锁和焦点恢复仍由原实现处理。

全屏按钮保留原本地化物品名称和操作提示。面板出现时 aria-describedby 指向以批次／记录 ID 命名的摘要，仅包含本地化稀有度及存在的 Metadata；名称已由按钮标签提供，不重复加入摘要。三行视觉内容对读屏隐藏，由独立的屏幕阅读器文本提供描述，避免图标和相邻文字重复播报。面板消失时描述关联同时移除，不额外播报 live region，不移动焦点。

## 维护者本地复现

运行 `npm run dev`，打开 `http://127.0.0.1:5173/tests/manual/warp-results/index.html`（端口以本机 Vite 输出为准）。先选场景，再点击“播放当前场景演出”。测试页使用明确标识的人工展示记录，不调用引擎或保存正式会话。

1. **四类信息**：依次检查三星光锥、四星角色、五星角色、合成五星光锥单抽。面板应为名称／裁切星级／Metadata 三行，光锥无属性，三档星星不拉伸，属性颜色和本地化名称正确。
2. **时机与确认**：五星 identity 阶段不出现面板；命途＋Star5 淡出后图片与面板一起淡入。前置点击只跳到当前图，淡入时点击不提前推进；waiting 中点击面板各处均能确认当前项。Escape、长按、快速重复输入保持既有语义。
3. **多五星与 Reduced Motion**：五混十连逐个确认，面板对应当前记录且不串项；最后才显示完整结果。初始和运行中启用 Reduced Motion 均检查，图片与面板直接停留等待确认，退出焦点回到原按钮。
4. **名称与缺失字段**：选择新增“正式英文最长名称光锥单抽”“合成超长名称角色单抽”“命途与属性 Metadata 缺失”，切换中英文。名称完整换行、无横向溢出；缺失 Metadata 显示未知，其他场景只有实际存在的分组。
5. **图片与加载异常**：原“缺图／请求失败／极端宽高比”可检查很宽／很高图片；原“单抽缺图及图标”“单抽高清与轻量图片均请求失败”“五星高清失败后回退轻量图片及图标”检查 Artwork 占位、坏星级、图标占位。使用网络限速确认面板不会在 Artwork 就绪前空播，也不会额外阻塞确认。
6. **响应式与可读性**：1440、1920、1024、640、390、320px，横屏例如 844×390，以及 DPR 1／2／3、浏览器缩放 80%／100%／125%／150%。检查面板相对舞台而非 Viewport 定位、名称／Metadata 换行、人物面部与封面主体遮挡、属性文字可读性、面板与底部提示之间的距离。现选择不会贴合实际缩小后的图片外框。
7. **读屏与回归**：键盘 Enter／Space 和读屏检查原操作提示仍在，最终图额外提供稀有度及 Metadata，不重复读图标和名称；identity 没有失效描述引用。正式抽卡核对历史、保底、Drawer、普通卡片和图片表现保持原样。

正式 Snapshot 仍无五星光锥；其样式用原合成身份和已有四星封面验证。新超长名称角色同样只在夹具 Snapshot 中复用现有角色素材，没有进入正式卡池、运行时 Snapshot 或 Catalog。
