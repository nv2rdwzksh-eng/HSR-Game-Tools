## 组件、状态机与提交时序

### 职责

- `useWarpReveal(reducedMotion)` 管理批次、只读展示引用、队列游标、阶段和唯一阶段计时器；不导入引擎实现、不保存或更新保底。
- `WarpRevealOverlay` 接收 visible／entry／item／phase，发送 activate／escape／after-hide；只负责视觉、键盘和局部模态焦点。
- `useWarpReducedMotion` 订阅浏览器媒体查询，并在作用域销毁时移除监听器。
- `result-presentation` 在 UI 层提供三行纯文本 Tooltip 和共享稀有度 CSS 变量映射，翻译仍由 i18n 提供。

`WarpSimulatorPage` 通过 flush: sync watcher 监听 `session.latestBatchId`，只在新批次提交后将 `latestResults` 交给演出。原 `useWarpSimulator.draw()` 保持原字节：一次调用 pullOnce／pullTen，成功后立即原子提交引擎状态、历史和最新批次，再由 UI 消费。

演出保存的 pending／displayedEntries 仅是已有只读记录的展示引用。正式历史和最新批次已经更新；有演出时普通结果区继续展示上一批引用，在整队列结束且 Dialog after-hide 后才发布完整新批次。这避免提前显示结果，也让卡片入场动画在返回普通页面时开始。无演出时立即发布新批次。

### 阶段

| 阶段    | 时长与操作                                                          |
| ------- | ------------------------------------------------------------------- |
| idle    | 无演出；无计时器                                                    |
| intro   | 五星命途：400ms 淡入、300ms 停留、400ms 淡出                        |
| stars   | 五星星级：400ms 淡入、300ms 停留、400ms 淡出                        |
| artwork | 完整图片淡入 400ms；此时点击不推进                                  |
| waiting | 图片持续停留，不再设置自动推进计时器；点击／Enter／Space 确认当前项 |
| leaving | 当前项离场 400ms；忽略重复激活，随后进入下一项或关闭 Dialog         |

单抽三／四星从 artwork 开始；五星从 intro 开始。前置 intro／stars 中点击只跳到当前 artwork，不丢弃当前记录。Escape 可结束当前项，进入下一个五星，最后一项完成才返回完整结果；键盘长按重复事件被阻止。

十连无五星不打开 Overlay；单五星只播放一项；多五星使用 filter 保持真实顺序，不按稀有度、UP 或名称排序，不合并展示。

Reduced Motion 初始直接 waiting；运行中启用会清理当前阶段计时器，直接显示最终 Artwork。若启用时正在 leaving，则立即完成该项离场。最终图片仍须用户确认；CSS 同时支持系统媒体查询，测试页模拟直接 waiting 时也不会触发 Artwork 入场动画。

每次阶段／批次变更清除原计时器并递增版本标识，迟到回调不能进入旧阶段。同一或更旧批次不重复播放；替换批次、全部重置和作用域销毁清理待展示状态。隐藏回调只有在当前批次已完成离场且不可见时才能发布结果，不能释放仍可见的替换批次。

## 资源、纯黑背景与可访问性

Overlay 使用现有 PrimeVue Dialog 的模态、焦点陷阱、滚动锁和 ZIndex。仅该实例 unstyled；通过专用 wrapper class 设置 mask／root 以及全屏按钮背景为 `#000000`，无主题遮罩渐变、边框、圆角或装饰阴影，也不触发浏览器 Fullscreen API。Dialog 自身 CSS 过渡关闭，物品阶段动画由上述状态机和 CSS 控制。

角色与光锥都从已有 Presentation Adapter 取得已验证资源，在全屏中完整 contain、居中显示；不使用结果卡的 crop，不改游戏素材或生成管线。命途与星级使用现有原生 Icon 图片。缺少 URL／请求失败沿用中性占位，不能影响队列或业务状态，也不会导致自动推进。

全屏按钮具有双语物品名称及操作提示，可通过点击任意位置、Enter／Space、Escape 操作；显示简短操作提示。打开后主动聚焦该按钮。页面根节点 inert，抽取按钮和已有控制入口在演出及隐藏完成前保持锁定；最后 after-hide 解除门控，再按稳定 ID 恢复发起单抽／十连按钮焦点。原 Drawer／详情转场仍由 `useWarpOverlay` 管理，未修改其实现。

Tooltip 使用安全文本节点和 `white-space: pre-line`，中文示例为三行 `真珠（欢愉·冰）`、`稀有度：5 星`、`类别：角色`；英文采用本地化括号、分隔符和标签。仅连接已有元数据，光锥没有属性，缺少全部元数据时首行仅有名称。未经处理的名称文本不会作为 HTML 插入。独立详情 Dialog 和原 ARIA 摘要继续提供完整信息。

## 维护者本地人工验收

1. 使用 Node 24，运行 `npm run dev`，打开终端地址下的 `/tests/manual/warp-results/index.html`。该开发入口不是生产路由，也不由 npm run preview 提供。现在有 12 个固定场景；普通结果可直接检查，点击「播放当前场景演出」运行正式状态机；下方历史使用正式历史组件。
2. 分别选三星光锥、四星角色／光锥单抽，确认纯黑全屏、图片淡入后停留；前 400ms 点击不能关闭。选五星角色／合成五星光锥，确认命途→Star5→Artwork 的衔接，无背景装饰或持续闪烁。
3. 在五星 intro／stars 中快速点击，确认仅跳到当前 Artwork，随后仍须等待淡入完成再确认。长时间等待不能自动关闭。用点击、Enter／Space、Escape 分别确认；长按键盘不应连续跳过队列。
4. all-three／four-mixed 播放按钮不打开演出；ten-one-five 只演出一项；five-mixed 应依次演出原第 1、3、6、7 项。每项图片均停留，Escape 只结束当前项。全部结束后核对完整结果和原始顺序，检查普通卡片入场没有提前播完。
5. **正式 Snapshot 没有五星光锥。** 合成身份明确使用测试名称并复用四星封面，只验证五星光锥显示与队列，不证明真实五星光锥素材构图。禁止通过改生产卡池复现。
6. 勾选模拟 Reduced Motion 后播放，确认直接出现最终图片且无淡入、仍等待确认。在浏览器开发者工具中运行时切换 prefers-reduced-motion，确认当前前置阶段立即进入图片、离场不留异步回调。检查 missing-artwork／failed-artwork 的占位与可退出性。
7. 在 1440／1920px 检查 3–4–3、图标放大并统一左边缘、UP 有无及光锥空属性槽不造成位移；鼠标移出后紫／金外光仍明显。补查 1040／1039、641／640、390、320px，无卡片／图标溢出、Glow 裁切或横向页面滚动。
8. 中英文检查整卡 Tooltip 三行独立显示；角色包含属性，光锥不含属性，点击详情仍正常。检查历史正文、三档名称颜色、Hover 下划线、Focus 轮廓、窄屏内部滚动和名称截断。
9. 正式 `/warp-simulator` 完成选择后实际单抽／十连，检查 Overlay 打开时背景不能滚动或再次抽取，焦点限制在演出中；最后退出恢复发起抽取按钮。比较演出前后保底及历史计数；反复看详情、切换语言及面板不应改变结果。用超过 25 条真实历史检查原分页和详情返回焦点。
10. 在慢速／失败图片请求、页面离开再返回、移动端竖屏／横屏、屏幕阅读器下检查资源降级、清理、纯黑背景、完整图像及可访问操作。浏览器计时、图片实际解码与 CSS 视觉质量不由 Node 测试保证。
