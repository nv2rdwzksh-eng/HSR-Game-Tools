# Phase 1D：跃迁模拟器纯引擎实施

日期：2026-10-15（Asia/Shanghai）。目标仓库：HSR-Game-Tools，分支：develop；实施基线 HEAD 为 `f86b68fdb5c365e7b5845ba0bdc28b55d0a32c87`。现行规则见[跃迁引擎架构](../../architecture/warp-simulator.md)，本报告记录实施与测量，不授权下一阶段。

## 交付与公开接口

新增 `src/tools/warp-simulator/engine/`：`probability.ts`、`resolver.ts`、`state.ts`、`gacha.ts`、`types.ts` 及通用输入诊断 `validation.ts`。这是新写的纯 TypeScript 引擎，没有迁移旧站源码，没有引入运行时依赖、Pinia、页面或路由。

公开调用为 `resolvePool(snapshot, bannerId, { selectedAvatarIds? })`、`createSessionState()`、`pullOnce(pool, state, rng)`、`pullTen(pool, state, rng)`。解析和抽取使用成功／诊断联合结果；抽取返回事件和新状态，不修改输入。ResolvedPool、候选及物品只读且冻结；事件保留抽前状态、模型、Banner、继承组、抽样分支及 canonical ID 判断的最终 UP 事实。

概率曲线采用维护者确认的 `hsr-warp/v0.3`，没有继续调查或修改参数。五星先判，四星为五星未命中后的条件概率；角色／Ordinary 和光锥分别采用第 74／66 抽开始提升的五星曲线，以及各自四星 Soft Pity。Hard Pity 为五星第 90／80 抽、四星第 10 抽。

角色五星回退为 UP 加显式七名选择，允许 UP 占两个槽位；光锥为 UP 加人工配置的七张固定光锥。普通 Event 四星的回退候选统一按物品等权抽取，不先选择类型。最终命中 UP 就清除保证，非 UP 才激活保证；Fate 没有四星 UP，Ordinary 没有任何 UP。

保底按五个既有 `pityGroup` 隔离，同组切池或改变选择保持计数和保证。四星计数在 9 饱和，五星只增加该计数，不清除待兑现的四星保证或四星 UP 标志。十连顺序使用单抽相同转移，后段 RNG 失败时整批不返回成功前缀；外部 RNG 进度不回滚。

## 确定性与独立数学验证

新增五个引擎测试文件、134 项测试；加上原有 Warp 数据测试，Warp 共 175 项。覆盖五类池、全部指定概率边界、阈值相等的失败侧、双重 Hard Pity、连续五星挤占四星、两种保证激活／兑现／清除、回退命中 UP、重叠权重、同 ID 不同对象、同组继承与组间隔离、无 UP 行为、十连等价及 RNG 消费一致。

失败验证覆盖未知／重复身份、错误类型及星级、错误组、候选不足、空／重复／稀疏候选、缺少或非法选择、非法模型与计数、无适用机制的保证、非法或抛错 RNG。即使当前保证路径不会用到某个候选集合，也在消费 RNG 前检查该集合。另检查状态与事件不引用调用方可变输入，以及引擎导入不跨越纯 TypeScript 边界。

独立 Oracle 位于 `tests/fixtures/warp-simulator/oracle.ts`，不导入生产概率函数、状态转移或抽样器。它以千分整数表达独立 hazard，通过五星生存函数计算 `E[T] = Σ S(n)` 和 `1/E[T]`；通过联合五星／四星未命中状态做概率质量转移求稳态，L1 残差要求不超过 `1e-13`。Oracle 独立保留四星第 10 个未命中桶，生产状态饱和于 9；两种表示的长期结果一致。

| 模型           | 平均五星等待抽数 |      长期五星率 |       长期四星率 | 稳态迭代次数 |
| -------------- | ---------------: | --------------: | ---------------: | -----------: |
| 角色／Ordinary |  62.297332039631 | 1.605205178554% | 12.955843188005% |         4432 |
| 光锥           |  53.411048379173 | 1.872271805827% | 14.499985462884% |         3349 |

五星更新过程与联合状态的五星率差异小于 `3e-14`，总概率质量与 1 的差异小于 `3e-13`。独立计算与附件的长期参考值一致；未为拟合阈值调整模型。

测试另逐一枚举非保证分支与槽位，使用真实单抽返回的 Item ID 累加理论概率质量，精确验证角色无重叠 56.25%、有重叠 62.5%、光锥 78.125%。四星枚举验证每个候选概率、回退再次命中 UP，以及保证状态的三个等权结果。全部五类每个合法计数对也与独立 hazard 及无条件结果分布交叉核对。

## 固定 Seed Monte Carlo

显式命令：`node --import tsx tests/experiments/warp-simulator.ts`。不加入普通 Vitest 执行，不设随机通过阈值。实验使用实际 `pullTen`，每个模型 20 个独立重置会话，每个 50,000 抽，共各 1,000,000 抽；只保留当前十个事件及计数。

RNG 为测试辅助 Mulberry32（32 位无符号状态），角色首 Seed 24302、光锥 24303，各会话 Seed 为 `首 Seed + 997 × 会话索引`，索引 0…19。每个会话从五组计数为零、保证为 false 开始。采用仓库测试合成 Snapshot 的完整卡池夹具，角色选择 `avatar:1`…`avatar:7`，五星 UP 为 `avatar:9`，不存在重叠；光锥回退为 `light-cone:1`…`light-cone:7`，UP 为 `light-cone:8`。夹具的同名条目用于验证身份不依赖名称，不代表真实候选名单。

| 模型       |  五星次数／频率 |    四星次数／频率 | UP 五星次数／频率 |  RNG 消费 |
| ---------- | --------------: | ----------------: | ----------------: | --------: |
| 角色 Event | 16,090／1.6090% | 129,391／12.9391% |   11,185／1.1185% | 3,083,046 |
| 光锥 Event | 18,670／1.8670% | 144,848／14.4848% |   15,253／1.5253% | 3,107,116 |

| 模型       | 五星偏差（百分点） | 五星均值标准误（百分点） | 四星偏差（百分点） | 四星均值标准误（百分点） |
| ---------- | -----------------: | -----------------------: | -----------------: | -----------------------: |
| 角色 Event |          +0.003795 |                 0.004199 |          −0.016743 |                 0.012821 |
| 光锥 Event |          −0.005272 |                 0.005648 |          −0.015185 |                 0.015426 |

标准误由 20 个会话频率的样本标准差除以 `sqrt(20)` 估计，不把单次抽取当独立 Bernoulli。它描述本次分批样本的波动，不是服务器模型认证或严格随机认证。含歪后保证的长期 UP 五星理论率为 `五星率 / (2 − q)`，q 为非保证最终命中率；角色约 1.116664%、光锥约 1.536223%，本次样本偏差分别约 0.45 和 −1.72 个会话均值标准误。统计结果仅作确定性和数学验证的补充。
