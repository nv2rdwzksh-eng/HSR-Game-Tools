## 演出与加载时序

状态为 `idle → identity → artwork → waiting → leaving`；三／四星单抽跳过 identity，十连无五星直接发布普通结果，多五星按实际记录顺序逐项播放。

1. 当前五星挂载命途、Star5 和隐藏的当前 Artwork；不预加载整个队列。
2. 命途与 Star5 都加载成功或回退到最终占位后，发出带 batchId／entryId 的 identity-ready。组合内命途在上、星级在下、间距 24px，共同淡入 400ms、停留 300ms、共同淡出 400ms。
3. Artwork 或其最终占位就绪后淡入 400ms，再进入 waiting。加载期间不启动确认计时，最终图片不自动消失。
4. identity 点击只跳到当前 Artwork；加载／淡入期间点击不推进。waiting 点击／Enter／Space 才离场 400ms并进入下一项。
5. Escape 可在加载和任意阶段结束当前项；离场重复输入、长按重复键不推进额外条目。最后一项 after-hide 后发布完整批次并恢复发起抽取按钮焦点。
6. Reduced Motion 跳过 identity 和淡入／淡出，但仍等待当前图片或最终占位就绪后确认；运行中启用会取消动画计时。页面 inert、模态、滚动锁和退出焦点沿用现有行为。

`useWarpReveal` 仅消费已提交的 HistoryEntry／PullEvent。页面仍监听已提交 latestBatchId；没有改 `useWarpSimulator` 的抽取、原子提交、历史或保底。旧异步资源回调必须匹配当前批次和记录；阶段计时器带版本，替换批次、关闭、重置和卸载清理。新增同步 ready 重入防护，避免占位立即就绪时重复排程；过期计时回调不能擦除当前计时句柄。

新增 `WarpRevealImage`、`useWarpRevealSource` 和 `useWarpPixelRatio`。高清缺失／失败依次回退轻量图片、中性占位；只有当前组件的 img 请求资源，没有后台下载整个队列。DPR 初值在挂载后读取，订阅 resolution、window.resize 与 visualViewport.resize，卸载移除监听。图像使用 naturalWidth／naturalHeight，显示范围同时受视口、既有最大宽 1200px 和自然像素／DPR 限制。DPR 2 下原生 1260px 高光锥最高 630 CSS px；低清 640px 回退最高 320 CSS px。实际浏览器 DPR 与缩放行为尚待人工测量。

## 星级约束

信息栏和每个槽位采用 `grid-template-columns: minmax(0, 1fr)` 与 min-width: 0。父级仅传目标尺寸变量：普通图标 36px、星级宽 80px，单抽 48px、星级宽 100px。WarpVisualIcon 统一计算目标与可用宽高的较小值；三档星级均为 `width: min(var(--warp-stars-width, 80px), 100%)`、height auto、aspect-ratio 5/1，内部图片 max-width 100%、contain。移除父级重复的 deep 固定宽高覆盖，不截断第五颗星。

自动测试验证原生三档资源尺寸、共享约束结构与调用隔离；这些静态断言不能代替四卡并排、浏览器缩放和窄屏实际像素验收。

## 维护者本地人工验收

运行 `npm run dev`，打开 `http://127.0.0.1:5173/tests/manual/warp-results/index.html`（以实际 Vite 端口为准）。该入口独立于生产路由，不保存会话；先选场景，再点击“播放当前场景演出”。正式 Snapshot 无五星光锥，合成五星光锥复用既有四星封面和对应高清资源，只用于展示验证。

1. **同步组合**：五星角色和合成五星光锥单抽。黑底必须纯黑，命途与完整五颗星一起淡入、停留、淡出，之后 Artwork 淡入并永久停留。identity 早点击只跳到当前图；淡入中点击不跳过结果。
2. **队列与输入**：三星／四星单抽直接 Artwork；无五星十连直接 3–4–3；单五星十连演出一次；多五星按记录原顺序逐项确认后才显示完整十连。触屏、Enter／Space、Escape、重复输入、背景滚动锁、退出焦点均检查。
3. **慢网与回退**：在开发工具限制网络后重播；命途／星级共同就绪后才出现，Artwork 加载完才开始淡入与确认门控，Escape 仍能结束当前项。“五星高清失败后回退轻量图片及图标”验证有序降级；“单抽高清与轻量图片均请求失败”和“单抽缺图及图标”检查中性占位仍可确认、没有空播或卡死。切换／重播后旧请求不能推进新项。
4. **清晰度与 DPR**：DPR 1／2／3、浏览器缩放 80%／100%／125%／150%，并跨不同 DPR 屏幕或使用开发工具模拟。查看实际 devicePixelRatio、自然尺寸与渲染尺寸；角色和封面保持完整居中、不变形，光锥高度不超过原图高／DPR。DPR 高时图片变小是保真策略；记录实际可读性与源图本身的模糊程度。
5. **星级与布局**：1440、1920、1024、640、390、320px，中英文；重点检查四卡并排、单抽大卡、浏览器缩放和五颗星完整性。三档星级不跨槽／越框，三个槽位左边缘一致，光锥缺属性不移位。普通结果图片构图、3–4–3、Glow 外缘和间距应与已验收版本一致。
6. **减少动态效果**：系统 Reduced Motion 及验收页模拟开关；加载后直接最终图，仍须确认，多五星逐项等待；运行中开启应取消动画，无遗留回调或焦点丢失。
7. **请求隔离与真实回归**：清空网络记录，普通十连／详情不请求 reveal 变体；播放时只请求当前项高清 Artwork 及五星 identity 图片，不提前加载整队列。正式页面实际抽取后核对历史／保底已提交，关闭／Escape 不改变它们，历史分页／详情与 Drawer 操作保持原样。
