# 货币战争优化器 UI 优化实施报告

> 历史记录：其中 Top-3、多方案接口、预算分割及旧 UI 描述已由 2026-10-20 单方案双目标重构取代；现行行为见[货币战争指南](../currency-wars.md)。原有测量与提交信息保留为历史证据。

日期：2026-10-16。工作分支：`develop`，实施基线：`486bc15`。需求依据为本轮 UI 优化文档、附带概念图及用户确认的独立星徽槽布局。

## 布局与交互

- 配置区改为目标任务、编队限制、高级设置、开始求解。已选列表显示图标、名称、人数门槛与移除按钮，最大高度 300px；编辑入口常驻列表外。移除后焦点转到相邻按钮，最后一项移除后转到编辑入口。
- 保留原有分类任务弹窗、全选、清空和独立草稿；确认应用，取消／Escape／关闭丢弃。专家开关与时限默认折叠，非法时限提交仍会展开并关联错误。
- 结果调整为推荐阵容、两个摘要 Tag、带图标的横向目标任务列表、折叠详情。移除巨大完成数字和单独角色数量；最优性状态放入详情，可行但未证明最优和保守模型警告直接显示。
- 角色卡片左对齐、自动换行，默认宽 128px，480px 及以下为 104px。费用标签在左上角，头像下方保留三个独立、等宽星徽槽；角色详情、专家／形态信息和图片回退保留。
- 桌面配置栏 320px，960–1199px 为 300px，低于 960px 单栏。任务说明在较窄窗口换行，长文本允许收缩和换行。视觉沿用现有主题与 Token，未引入 UI 依赖。

## 数据、资源与状态边界

展示目录增加可选 `traits` 映射，按稳定数字 ID 查找本地 WebP。统一羁绊组件用于已选任务、弹窗、结果及激活羁绊；图片保持比例，不使用概念图示意图标或远程资源。旧目录缺少映射、文件缺失或加载失败时显示中性占位并保留名称。

本地已有的 32 个文件均经图片元数据读取确认是 256×256 WebP，未修改文件内容。映射和 SHA-256 已纳入展示 Manifest，转换版本递增至 2，目录 schemaVersion 保持 1。Manifest 明确说明羁绊资源来自用户提供的本地文件；上游锁定 Commit 只承担既有费用来源等职责。

**缺失资源：`1014（师徒）`。** 当前 25 项正式目标任务均有图标；缺失项在其他适用位置使用占位，不阻塞 UI 和求解。补入资源后需显式更新展示目录及 Manifest。

默认 13 槽、12 星徽、排除专家、30 秒、全部 25 项任务保持不变。核心快照、任务文件、费用／头像／星徽既有映射、算法、Worker 协议和 CLI 未改变。两个摘要只读取 `SolvedAttempt` 的请求与结果；修改表单不会改写历史方案的预算、总任务数或完成数。失败、无结果、取消、迟到响应和过期判断继续使用原会话机制。

## 本地人工验收建议

1. 分别在 1440px、1024px、390px 与中英文检查双栏／单栏、角色自然换行、名称和星徽槽对齐、横向溢出及焦点轮廓。
2. 核对全部任务图标和人数门槛；逐项移除，检查焦点转移、数量更新、空选择提示和禁用求解；重新编辑后恢复任务。
3. 在任务弹窗操作单选、全选、清空、确认、取消、Escape 和关闭；确认前不应改变主页面或有效结果，重开应恢复已提交选择。滚动时数量和底部操作保持可见。
4. 完整求解，检查阵容优先、两个 Tag 和任务实际统计；修改预算或任务后应显示过期提示，旧结果的总任务数和预算仍对应原请求。求解期间编辑条件、取消后重新求解，以及新求解失败／无结果时应保留有效方案。
5. 点击或键盘打开角色详情，核对固有／额外羁绊、专家、开拓者形态、领航员目标、布洛妮娅归属；检查关闭焦点恢复和新有效结果替换时关闭旧详情。
6. 展开激活羁绊、贡献者、特殊机制及求解详情；检查最优／可行可区分，警告直接可见，原条件、耗时、原始状态和实际返回的上界／Gap 保留。
7. 临时阻止头像、星徽和羁绊图片请求，检查稳定占位与可读名称；用键盘查看星徽和帮助 Tooltip，并在根路径及 `/hsr/` Preview 核对资源无 404。
