## 校准工具与 JSON 操作

1. 在项目根运行 `npm run dev`，打开开发服务的 `/tests/manual/warp-results/index.html`，展开“头部锚点校准”区域。
2. 按中文名、英文名或 ID 搜索角色。列表显示已有覆盖状态，默认预览“十连总览”，也可切换“普通结果卡”。
3. 在完整立绘上点击或拖动头部中心，或通过键盘编辑 X、Y、scale。点击排除等比显示的留白，拖动到边缘时钳制到画布范围；坐标以完整源画布为准。
4. 右侧复用正式卡片，实时显示裁切、属性、真实星级和背景。可开关中心准星；“重置为默认参数”使用全局默认，“恢复源配置”恢复本次页面打开时的正式配置。
5. 切换角色／预览类型保留本页草稿。点击“导出 JSON”下载完整配置，保留其他角色及两种卡片配置。角色键排序，字段按 x、y、scale 排列，总览只保存相对普通配置的差异。
6. 将下载文件替换 [portrait-focus.json](../../../src/tools/warp-simulator/data/portrait-focus.json)。这是导入正式配置的方式，无需重新生成图片；刷新开发页面后读取新配置。页面没有自动写入工作区，未导出的草稿刷新后会丢失。
7. 替换后运行 `npm run type-check` 和 `npm test -- tests/unit/warp-simulator/portrait-calibration.test.ts`。

正式 JSON 是唯一权威来源，结构为 `default`、`overrides` 和 `overviewOverrides`。默认 `(0.5, 0.3, 2)`，角色 ID 为稳定 `avatar:<ID>`，X／Y 范围 0–1、scale 范围 0.1–8。原有十个人工覆盖及阿兰／昔涟的总览差异已保留，其他角色使用默认值。严格校验用于测试及导出；非法手工编辑会报告诊断，并在运行时使用安全默认值。

工具只在开发 HTML 入口引用，不注册生产路由。生产输出检查未发现校准组件、开发入口、准星、校准文案或 review.calibration 标识。

按仓库默认政策，本次未执行真实浏览器自动化或截图验收。Node 挂载测试不计算 CSS 布局，也不代表用户视觉验收。
